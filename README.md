## ⚡ Local Development

```bash
# 1. Clone the repository
git clone https://github.com/rahadhasan666/bengalit.git

# 2. Navigate to directory
cd bengalit

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```

App will be live at `http://localhost:5173/`.

### 📦 Production Build

```bash
# Validate types and create production bundle
npm run build

# Preview production build locally
npm run preview
```

## 🌐 Deploying to Vercel

This repository is pre-configured for seamless 1-click deployment on **[Vercel](https://vercel.com/)**:

1. Go to **Vercel Dashboard** → **Add New Project**.
2. Import **`rahadhasan666/bengalit`**.
3. Framework Preset: **Vite** (Automatically detected via `vercel.json`).
4. Build Command: `npm run build`
5. Output Directory: `dist`
6. Click **Deploy**.
